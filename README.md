

🌤 Weather App

A smart, clean, and powerful Weather App built using HTML, CSS, and JavaScript.
It provides real-time weather information with charts, dark/light mode, voice assistance, and location-based weather detection.
## 🚀 Features

* 🔍 City-based weather search
* 📍 Current location weather detection
* 🌡 Temperature, feels-like & rainfall info
* 📊 Hourly temperature visualization (Chart.js)
* 🌙 Dark / Light mode toggle
* 🔊 Voice assistant reads weather aloud
* 🕒 Displays local time of the city

---

## 🛠 Tech Stack

| Technology       | Usage                |
| ---------------- | -------------------- |
| HTML5            | App structure        |
| CSS3             | Styling & animations |
| JavaScript (ES6) | Logic & API calls    |
| Open-Meteo API   | Weather data         |
| Chart.js         | Temperature graph    |
| Web Speech API   | Voice output         |
| Geolocation API  | Live location        |
